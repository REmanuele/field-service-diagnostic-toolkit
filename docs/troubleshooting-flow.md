# Troubleshooting Flow

This checklist describes the diagnostic method followed by the toolkit.

1. **Identify the symptom**  
   What is not working? When did it start? Is it reproducible?

2. **Collect information**  
   Gather system, network and service status before applying changes.

3. **Check connectivity**  
   Verify IP address, gateway, DNS and internet reachability.

4. **Check services**  
   Verify whether the expected services are active and inspect recent logs.

5. **Isolate the failing component**  
   Separate network, OS, application and configuration issues.

6. **Apply one fix at a time**  
   Avoid changing multiple variables together.

7. **Validate**  
   Re-run checks and confirm that the issue is actually solved.

8. **Document**  
   Save the diagnostic report and write a short note about the root cause.
